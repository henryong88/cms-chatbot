The "Ask CMS" chat assistant for cmspl.biz.

== Description ==
Adds the "Ask CMS" button to the bottom-right corner of every page. Visitors get CMS's approved answers, AI-assisted replies, delivery estimates from the CMS rate card, and a short form that sends their enquiry to the CMS sales team (monday.com Leads board and email).

Self-contained: one JavaScript file, no settings page, no database tables, no cookies. It runs inside a Shadow DOM, so the theme's styles cannot affect it.

== Installation ==
1. Plugins > Add New Plugin > Upload Plugin.
2. Choose cms-chatbot.zip, then Install Now.
3. Activate.
