Install guide for the web developer

The “Ask CMS” chat assistant for cmspl.biz. Install takes about five minutes and needs no server work, database or API keys.

What's in this package

FileUse it for
1-WordPress/cms-chatbot.zipA WordPress plugin. Upload, activate, done. Use this if the site runs on WordPress.
2-Any-other-website/
cms-chatbot-snippet.html		The same chatbot as one <script> block, for Webflow, Wix, Squarespace, Shopify, a custom build, or WordPress without plugins.
CMS-Chatbot-Install-Guide.pdfThis guide.
Recommended

Option A: WordPress plugin

  1. In WordPress admin, go to Plugins → Add New Plugin.
  2. Click Upload Plugin, choose cms-chatbot.zip, then Install Now.
  3. Click Activate.
  4. If the site uses a cache or optimisation plugin (WP Rocket, LiteSpeed, Autoptimize and so on), clear its cache.

The button appears in the bottom-right corner of every page. To update later, upload the new zip and choose Replace current with uploaded.

Any other website

Option B: paste the snippet

  1. Open cms-chatbot-snippet.html in a text editor and copy everything.
  2. Paste it once into a site-wide area that loads on every page, just before </body>: the custom-code / footer-code setting, or the theme footer.
  3. Publish.

Use either A or B, never both. If both are used by mistake, the script still loads only once.

!Two things to do on the new site

1. Remove the old floating WhatsApp button (“Need Help? Chat with us”, bottom-right). CMS has decided the chatbot is the only chat button on the site. It already hands visitors to WhatsApp and sends job seekers to the Join Our Team page.
2. Keep the Join Our Team page at https://cmspl.biz/join-our-team/, or tell CMS its new address so the link can be updated (see settings below).

How it works (no action needed)

  • Self-contained. One JavaScript file, about 100 KB, with no libraries. It renders inside a Shadow DOM, so theme styles cannot affect it and it cannot affect the theme. It uses no cookies, only the browser's session storage for the open conversation.
  • Approved answers are built in. Other questions get an AI-assisted reply through CMS's own Make.com scenario. The AI only uses CMS's approved information and never quotes prices.
  • Estimates come from the CMS rate card inside the script. Enquiries go to CMS's Make.com webhook, which adds them to the monday.com Leads board and emails the sales team.
  • If the AI service is slow or down, the chatbot carries on with the approved answers.

Optional settings

Change these only if needed. All other settings, including the webhook addresses and the rate card, are managed by CMS. Please leave them unchanged.

WordPress plugin: add a filter to the theme's functions.php or a code-snippets plugin:

add_filter( 'cms_chatbot_settings', function ( $s ) {
    $s['lift'] = 80;                                    // example
    $s['careersUrl'] = 'https://cmspl.biz/careers/';    // example
    return $s;
} );

Snippet: put this line just before the snippet:

<script>window.CMS_CHAT_SETTINGS = { lift: 80, careersUrl: "https://cmspl.biz/careers/" };</script>

Check it after installing

  1. Open the site on a phone and on a computer. The Ask CMS button shows in the bottom-right corner, and nothing else floats in that corner.
  2. Tap it and ask “What temperatures can your reefer trucks hold?”. You should get an instant answer.
  3. Ask “20 cartons frozen meat from Tuas to Changi tomorrow, how much?”. It should reply and start the estimate questions.
  4. Ask “Are you hiring?”. The Open Join Our Team page button should open the careers page.
  5. Please do not submit the enquiry form with test details, because it goes straight to the CMS sales team. If you must, put TEST in the company name.

Troubleshooting

ProblemFix
Button doesn't appearClear the site cache and any CDN cache (for example Cloudflare). In the browser console, check that cms-chatbot.js loaded.
Button shows only after scrollingA “delay JavaScript” optimisation is holding it back. Exclude cms-chatbot.js (or the snippet) from delay or defer.
Something covers the buttonUse the lift or side setting above.
Content Security Policy errorsAllow https://hook.eu1.make.com in connect-src, and fonts.googleapis.com and fonts.gstatic.com for the font.
